
# Iris Dataset Analysis and Visualization

## 📌 Project Overview

This project focuses on analyzing and visualizing the **Iris Dataset** using Python in Google Colab.

The dataset contains measurements of iris flowers from three different species: **Setosa, Versicolor, and Virginica**.

The project demonstrates basic data analysis techniques and data visualization using **Pandas** and **Matplotlib**.

---

## 🎯 Objective

The main objectives of this project are:

- To load a dataset into Google Colab.
- To understand the structure of the dataset.
- To analyze the data using Python.
- To identify missing values.
- To generate statistical summaries.
- To visualize the dataset using different graphs.
- To understand relationships between different flower measurements.

---

## 📊 Dataset Description

The Iris Dataset contains **150 flower samples** and **5 columns**.

### Features

| Feature | Description |
|---|---|
| Sepal Length | Length of the sepal in centimeters |
| Sepal Width | Width of the sepal in centimeters |
| Petal Length | Length of the petal in centimeters |
| Petal Width | Width of the petal in centimeters |
| Species | Species of the iris flower |

### Species

- Setosa
- Versicolor
- Virginica

Each species contains **50 samples**.
